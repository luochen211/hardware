### 三层之间怎样传递信息

```mermaid
flowchart LR
  subgraph D[感知层：传感、控制与执行]
    S[传感器] --> M[单片机与固件]
    M --> X[电机、灯或水泵]
  end
  subgraph N[网络层：传递数据和命令]
    L[串口 / 蓝牙 / Wi-Fi]
  end
  subgraph A[应用层：查看和操作]
    U[手机 / 网页 / 智能体]
  end
  M -->|设备主动上报的数据| L
  L --> U
  U -->|用户或程序发出的命令| L
  L --> M
```

**感知层**通过传感器接触真实物理状态，并由单片机控制本地动作；**网络层**传送设备选择上报的数据和下发的命令；**应用层**查看收到的信息，再通过开放接口发出命令。电脑连上设备，不等于能直接看到所有电气和机械状态。

例如，手机收到 ESP32 上报的土壤湿度值，只能说明设备发送了这个读数；要确认传感器供电和接线，还需要相应的诊断信息或实际测量。
