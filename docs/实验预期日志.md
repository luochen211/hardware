# 实验预期日志

本文逐个实验列出串口应当出现的日志，作为烧录后的对照表。

> **来源与可信度**
> - 日志由源码里的 `ESP_LOGx` 语句和程序流程**推演**得到，**没有在实物上逐项运行验证**。只有标"实测"的片段来自真实串口输出。
> - 时间戳（括号里的毫秒数）只是示例，实际会有出入。联网、蓝牙实验里 ESP-IDF 自己的 `wifi:`、`phy_init:`、`BT_` 等日志会穿插其中，本文不列出。
> - 日志格式为 `等级 (毫秒) TAG: 内容`，例如 `I (276) EXP2_GPIO: ...`。
> - 学号姓名目前仍是占位符 `2025xxxxxx` / `张三`（实验7、8A 的 `STUDENT_ID` 是 `2024001`），交作业前需要改成真实信息，日志里会同步变化。

## 通用启动日志（实测）

所有实验烧录后，芯片都会先输出下面这段，之后才进入各实验自己的日志。判断"程序有没有跑起来"，就看有没有最后的 `Calling app_main()`。

```
I (27) boot: ESP-IDF v6.1 2nd stage bootloader
I (29) boot: chip revision: v3.1
I (164) boot: Loaded app from partition at offset 0x10000
I (183) cpu_start: GPIO 3 and 1 are used as console UART I/O pins
I (189) app_init: Project name:     exp2_gpio_freertos
I (192) app_init: ESP-IDF:          v6.1
W (262) spi_flash: Detected size(8192k) larger than the size in the binary image header(2048k). Using the size in the binary image header.
I (276) main_task: Started on CPU0
I (276) main_task: Calling app_main()
```

其中 `spi_flash ... Detected size(8192k)` 那一行是警告，说明板载 flash 是 8MB 而固件按 2MB 配置，不影响运行。

## 按键相关实验的重要提醒

实验 2、4A、4B、6B、7、8A 的代码都假设按键或拨动开关接在 **GPIO22（K1_C）** 和 **GPIO21（K1_D）**。

但在智能家居板上做 GPIO 扫描时，按板上 `K1 / K2` 轻触按键，检测到的是 **GPIO36 和 GPIO39**（同一块板上还检测到过 GPIO22、GPIO23 的变化，来源尚未单独核实）。因此：

- 下面所有标"按键"的日志，都**以按键确实接到代码里的引脚为前提**。
- 如果按键没有反应，先确认实际引脚，不要先怀疑代码逻辑。

## 实验2：FreeRTOS + GPIO + 按键（`exp2_gpio_freertos`，TAG `EXP2_GPIO`）

启动部分（实测）：

```
I (276) EXP2_GPIO: ============================
I (276) EXP2_GPIO: 实验2：FreeRTOS多任务 + GPIO
I (286) EXP2_GPIO: 学号: 2025xxxxxx  姓名: 张三
I (286) EXP2_GPIO: ============================
I (296) EXP2_GPIO: WS2812初始化: SPI2 MOSI=GPIO14
I (296) EXP2_GPIO: blink_task 启动
I (306) EXP2_GPIO: button_task 启动
I (306) EXP2_GPIO: 3个任务已创建，开始运行...
I (306) main_task: Returned from app_main()
I (316) EXP2_GPIO: print_task 启动
```

按键操作后（推演，且要求按键接在 GPIO22）：

```
I (8000) EXP2_GPIO: >>> 短按 → 闪烁模式
I (12000) EXP2_GPIO: >>> 长按 → 切换呼吸灯模式
I (16320) EXP2_GPIO: 按键计数: 2 (学号:2025xxxxxx)
```

行为细节（均来自代码）：
- 开机后彩灯是**红色闪烁**，周期 1 秒；长按进入**绿色呼吸灯**；在呼吸灯模式下再次长按**不会有任何反应**，只有短按才能回到红色闪烁。
- 短按和长按都会让计数加 1。
- `print_task` **只在计数变化时才打印**，而且每 5 秒检查一次，所以按键后最多要等 5 秒才看到"按键计数"，没按键时没有周期打印。

## 实验5A：Wi-Fi 固定配置 + TCP（`exp5a_hardcode`，TAG `exp5` / `wifi`）

前提：必须先把 `wifi_connect.c` 里的 `YOUR_WIFI_SSID` / `YOUR_WIFI_PASSWORD` 改成真实热点，并把 `main.c` 里的 `TCP_SERVER_IP`（现在是 `192.168.110.222`）改成你电脑的 IP，且电脑上有程序监听 8080 端口。

成功路径：

```
I (276) exp5: === 实验五：WiFi STA + TCP 客户端 ===
I (...) exp5: OLED: SCL=GPIO19 SDA=GPIO18
I (...) wifi: WiFi STA 初始化完成，正在连接 <你的SSID> ...
I (...) wifi: 获取到 IP 地址: 192.168.x.x
I (...) wifi: ✅ WiFi 连接成功: SSID=<你的SSID>
I (...) exp5: Socket 创建成功，正在连接 192.168.110.222:8080 ...
I (...) exp5: ✅ 已连接 TCP 服务器 192.168.110.222:8080
I (...) exp5: 发送 [22 bytes]: {"temp":25,"humi":60}
I (...) exp5: 收到回显 [22 bytes]: {"temp":25,"humi":60}     ← 仅当服务器回显
```

- 每 3 秒发送一条；温湿度是**模拟值**，温度限制在 15–35，每次随机微调 ±1。
- OLED 先显示 `Exp5 TCP Client` / `Connecting WiFi`，获得 IP 后显示 `IP:x.x.x.x` 和温湿度。

失败路径：

```
I wifi: 重试连接 AP... (1/5)  …  (5/5)
E wifi: 连接失败，已达到最大重试次数
E wifi: ❌ WiFi 连接失败: SSID=...
E exp5: 连接服务器失败: errno=...     ← 电脑没开监听或 IP 不对
W exp5: 连接断开，5秒后重连...
```
