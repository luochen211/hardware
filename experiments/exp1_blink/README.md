# 实验 1：WS2812 RGB 彩灯

## 当前程序

ESP32 通过 SPI3 向 WS2812 发送颜色数据，依次显示红、绿、蓝、白和熄灭，每种状态约持续 1 秒，并在串口打印当前颜色。当前源码没有闪烁模式、呼吸灯渐变或模式切换开关。

## 引脚与时序

| 外设 | 当前源码配置 |
| --- | --- |
| WS2812 数据线 | GPIO14（`WS2812_MOSI_PIN`） |
| SPI 时钟 | 8 MHz（`WS2812_SPI_CLK`） |

源码将每个颜色位编码为一个 SPI 字节，按 GRB 顺序发送。WS2812 的实际接线应以所用实训箱原理图为准；不同资料曾写过 GPIO21、GPIO23，与本工程当前配置不一致。

## 编译与观察

```bash
cd experiments/exp1_blink
idf.py set-target esp32
idf.py build
idf.py -p <串口设备> flash monitor
```

烧录后观察彩灯是否按红、绿、蓝、白、熄灭循环，同时核对串口日志。构建成功不等于灯条已正确接线或点亮。
