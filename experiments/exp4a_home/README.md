# 实验4A：智能家居板执行器综合控制

## 功能

4个执行器同时运行（FreeRTOS多任务并行）：

| 执行器 | 引脚 | 功能 |
|--------|------|------|
| 蜂鸣器 | GPIO13 | 循环播放小星星旋律（LEDC PWM） |
| 步进电机 | IN1-4=26/25/33/32 | 正转1圈→反转1圈→循环（8拍驱动） |
| WS2812 RGB灯 | GPIO14 | 彩虹颜色渐变（SPI驱动） |
| 继电器 | GPIO17 | 拨动开关K1_C(GPIO22)控制开关 |

## 编译运行

```bash
cd exp4a_home
idf.py set-target esp32
idf.py build flash monitor
```

## 预期效果

- 蜂鸣器循环播放《小星星》
- 步进电机正转1圈停1秒，反转1圈停2秒
- WS2812持续红→绿→蓝渐变
- 拨动开关拨到C档时继电器吸合（可听到"嗒"声），拨离时释放
